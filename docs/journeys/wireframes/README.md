# J1 wireframes

Low-fidelity mockups for [J1 — First light](../J1-first-light.md). Grey boxes and real labels: they fix what is on each screen and what each control is called, not the visual design.

| PNG                                                  | Screen                                        |
| ---------------------------------------------------- | --------------------------------------------- |
| [01-first-run.png](01-first-run.png)                 | Rooms, first run, no legacy import            |
| [02-room-setup.png](02-room-setup.png)               | Rooms, editing a room, bulb chip menu open    |
| [03-library.png](03-library.png)                     | Library                                       |
| [04-track-open-create.png](04-track-open-create.png) | Movie: open or create a track                 |
| [05-editor.png](05-editor.png)                       | Editor with a room, File menu open, Lights on |
| [06-editor-no-room.png](06-editor-no-room.png)       | Editor with no rooms                          |
| [07-plugin-settings.png](07-plugin-settings.png)     | Emby plugin settings page, reduced to a link  |

Sources are in `src/`. `05` and `06` are generated by `src/gen-editor.py` so they stay consistent. Re-render all PNGs at 1280×800 from the repo root:

```bash
python3 docs/journeys/wireframes/src/gen-editor.py
node docs/journeys/wireframes/render.mjs
```
